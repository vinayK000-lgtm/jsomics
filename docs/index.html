How to use GEO DEG Analysis

1. Search by disease keyword (e.g. "breast cancer") to find GEO datasets, or enter a GEO accession directly (e.g. GSE12345).
2. Click Fetch samples to load sample metadata and auto-detect case/control groups.
3. Review and adjust the case/control sample assignments if needed.
4. Click Run DEG + AI to perform differential expression analysis cross-referenced with PubMed literature and interpreted by AI.
